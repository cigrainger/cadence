# Community expectations

Treat learners and contributors with respect. Musical experience, disability, background, language, gender and identity are not grounds for exclusion. Critique an idea or implementation without belittling its author. No harassment, threats, unwanted sexual attention, doxxing or discriminatory abuse.

Keep discussion relevant and assume good faith while taking reported harm seriously. Maintainers may edit or remove harmful content, lock a discussion or restrict participation. They should explain decisions when doing so does not expose someone's private information.

Report conduct concerns privately through a maintainer's available GitHub contact. If no private route is available, request one without naming affected people or posting sensitive details. Do not use a security vulnerability report for an ordinary disagreement.

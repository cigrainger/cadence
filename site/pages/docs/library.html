Work with your own music

Imported sheet music and your own compositions have different places in the library, with links between related versions.

MusicXML first, when available

MusicXML carries pitches, rhythms and score structure. It is usually the most direct route to editable notation. Cadence can display a broader range of scores than its editor can change.

Compose currently supports up to 128 complete bars, one part, one key and meter, and two voices per staff. Unsupported notation is reported rather than silently removed. Keep the original file.

PDF → reviewed draft

  1. Choose a PDF in the import window.
  2. Select the page or page ranges and, if useful, describe the passage.
  3. Choose the instrument, transcription model and reasoning setting.
  4. Read the per-page progress. The importer sends the selected page for each request, not the entire book.
  5. Compare the editable notation with the original. Correct pitches, rhythms, voices, ties and chord symbols.
  6. Mark the relevant source pages reviewed before using them as assessed practice material.

Page failures can be retried individually. A retry is another model request and can incur another charge. Completed pages are retained; a failed local save does not automatically start another paid request.

AI transcription is a draft. A confident-looking result can still be wrong. Original PDFs remain alongside the notation so you can check them. Review gates are part of the learning workflow, not proof of transcription accuracy.

Make a related composition

Creative answers, alternative endings and reharmonisations are saved in My compositions and linked to the source piece. The original stays available.

A reharmonisation changes the selected chord symbol in a full editable copy. Written accompaniment is not automatically rewritten. Compare generated bass and guide tones in the pathway, then edit the written parts in Compose if you want that change in the score itself.

Analysis and coaching

Open Score analysis to choose a passage and local key, add harmonic readings and leave explanations. Interpretations remain editable; different styles can support different readings.

Optional AI analysis and conversations are attached to the piece. Check the context shown before sending. Your book, score and composition are not included in the public Cadence repository.

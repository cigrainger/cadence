When something goes wrong

Keep the original and the pending result. A retry should not cost you the work you already did.

No sound, or sound that keeps playing

Check the Mac's output device and volume. Use Stop all in the bottom bar or ⌘. to stop playback, count-ins and active recording. A completed pending take is retained.

For live MIDI recording, use the keyboard's own sound. Cadence plays its accompaniment and recorded MIDI on replay. A device or output change can interrupt an active pass.

No MIDI input

Check the cable, select the input in Settings → MIDI, then refresh. Release keys and pedal before arming the activity. Use Clear held notes after a disconnect. The editor and exercises require explicit input activation.

Timing feels late

Calibrate for the current keyboard and audio output. Bluetooth audio can introduce variable delay. Use a stable output path and test the offset at a comfortable tempo. App timestamps do not prove acoustic timing accuracy on every setup.

An import is wrong or stalled

Compare the draft with the original and correct it before marking the page reviewed. Try fewer bars or a smaller passage description. Model choice and reasoning affect cost and duration; there is no guaranteed best model for every score.

Requests have a deadline. Cancellation may leave provider work chargeable. Multi-page imports retain completed pages, and you can retry one failed page without resending the whole book. A failed local save should be retried as a save, not as another model request.

A save warning appears

Use Try saving again after fixing available disk space or permissions. If the message says the file changed outside this session, preserve both copies and reopen. Avoid running two versions of Cadence against the same data folder.

Unreadable and future-version files are deliberately preserved. Restore a known-good complete backup with the app closed. Do not send the whole data folder to a public issue.

macOS refuses to open the download

Download the current release: 0.36.1 is Developer ID signed and Apple notarised, while 0.36.0 was not. Check that the ZIP came from this repository and matches its checksum. If the current app is still blocked, keep the exact macOS message for a bug report. Do not disable macOS security globally. Building from source is also supported.

Report a useful bug

Include the app version, macOS version, input/output setup, exact steps, expected result and what happened. Use an original example or a minimal file you have rights to share. Redact keys, file paths and personal information from screenshots.

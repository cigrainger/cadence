# Cadence 0.36.1 — a clearer path into your music

Cadence connects the music you want to play with listening, theory, focused instrument practice and your own creative ideas. This update strengthens saving and release distribution, and makes that learning journey clearer on the website.

## Changes

- A Developer ID signing and Apple notarisation workflow, with a stapled ticket and Gatekeeper verification for the public app ZIP. Signing credentials stay in the maintainer's Mac Keychain.
- Dedicated library and practice owners. Practice evidence and review progress are saved together before success is shown. A failed new-composition save cannot select an unsaved score, and late AI results cannot update removed pieces.
- Regression coverage for corruption, conflicting writes, old/future saved formats, first-install pathway persistence and observation through existing controls.
- A clearer homepage, visible bass movement in the G7/D♭7 comparison, correctly spelled guide tones and a new social preview.
- Tested release checks for signing identity, timestamps, entitlements, notarisation outcomes and source/build correspondence. No private user documents or credentials are included.

## Downloads

The tested app is **Apple silicon (arm64), macOS 14+**. Extract the ZIP and move Cadence to Applications. Quit the old version first. `BUILD.json` records the actual signing, notarisation, architecture and source digest. Check the download against `SHA256SUMS.txt`.

The matching source archive includes pinned dependency source archives. The CycloneDX inventory still identifies unresolved versions inside the upstream notation bundle; it is not a claim of a complete dependency graph.

## Preview boundaries

AI transcription needs review. Guitar microphone matching is monophonic. Physical MIDI/microphone behaviour, VoiceOver and Intel builds still need dedicated testing. Whole-app unit coverage remains around 11%, despite high coverage of the musical core and newly extracted persistence owners; native scenario checks supplement it. The app is not isolated by App Sandbox.
